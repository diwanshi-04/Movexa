#  Movie Recommendation System

A Machine Learning based web application that recommends movies 
based on user interest using **Content-Based Filtering**.

Built using **Python + Streamlit + Scikit-learn**.


---

## Features

 * Select a movie  
 * Get top 5 similar movie recommendations  
 * ML-based recommendation (TF-IDF + Cosine Similarity)  
 * Enjoy your Movies
---

##  ML Algorithm Used

### Content-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity

The system finds similarity between movie overviews
and recommends movies accordingly.

---

##  Tech Stack

- Python  
- Streamlit  
- Pandas  
- Scikit-learn
